# Capturas de tela

Esta pasta guarda as capturas usadas no README. Tire-as com a janela em 1280×720 e os dados de exemplo
(`db/dados.sql`), e salve com estes nomes exatos:

1. `01-clientes.png`: tela de Clientes com a lista e um cliente selecionado.
2. `02-veiculos.png`: tela de Veículos mostrando os três status e as motos.
3. `03-vendas.png`: aba "Nova venda" preenchida, com o resumo do desconto PIX.
4. `04-recibo.png`: recibo exibido logo após finalizar uma venda.
5. `05-historico.png`: aba "Histórico" com pelo menos duas vendas.
6. `06-concessionarias.png`: tela de Concessionárias.
7. `07-vendedores.png`: tela de Vendedores.
8. `08-erro-validacao.png`: formulário com erro de validação embaixo do campo.

O passo a passo de conferência das telas está em [`docs/checklist-telas.md`](../docs/checklist-telas.md).
